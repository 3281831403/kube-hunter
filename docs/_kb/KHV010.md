# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could create a role in the cluster. Creating roles might give an attacker the option to harm the normal behavior of newly created pods within the specified namespaces, or to escalate privileges by granting excessive permissions.

## Remediation

Restrict role creation permissions using Kubernetes RBAC. Grant the `create` verb on `roles` only to the users and service accounts that require it, and audit role creation events.
