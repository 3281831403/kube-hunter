# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could delete a cluster role. Deleting a cluster role might allow an attacker to affect access to resources across the whole cluster, disrupting the normal behavior of applications that rely on it.

## Remediation

Restrict cluster role deletion permissions using Kubernetes RBAC. Grant the `delete` verb on `clusterroles` only to the users and service accounts that require it, and audit cluster role deletion events.
