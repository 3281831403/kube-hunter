# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to a pod could read the secrets mounted into it. Accessing the pod's secrets within a compromised pod might disclose valuable data, such as credentials and tokens, to a potential attacker.

## Remediation

Mount only the secrets each workload actually needs, prefer environment-specific scoping and rotation of secrets, and consider using an external secrets store with fine-grained access control.
