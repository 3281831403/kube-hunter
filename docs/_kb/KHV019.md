# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could delete pods in the cluster. Deleting pods allows an attacker to disturb applications running on the cluster.

## Remediation

Restrict pod deletion permissions using Kubernetes RBAC. Grant the `delete` verb on `pods` only to the users and service accounts that require it, and audit pod deletion events.
