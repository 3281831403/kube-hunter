# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could create a cluster role. Creating cluster roles might give an attacker the option to harm the normal behavior of newly created pods across the whole cluster, or to escalate privileges by granting excessive cluster-wide permissions.

## Remediation

Restrict cluster role creation permissions using Kubernetes RBAC. Grant the `create` verb on `clusterroles` only to the users and service accounts that require it, and audit cluster role creation events.
