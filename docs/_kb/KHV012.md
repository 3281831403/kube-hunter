# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could patch an existing role. Patching a role might give an attacker the option to grant new permissions (such as creating pods with custom roles) within the specific role's namespace scope.

## Remediation

Restrict role modification permissions using Kubernetes RBAC. Grant the `patch` and `update` verbs on `roles` only to the users and service accounts that require it, and audit role modification events.
