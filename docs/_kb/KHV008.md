# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could create a namespace in the cluster. A new namespace gives an attacker an area with default (and possibly exploitable) permissions to deploy workloads in.

## Remediation

Restrict namespace creation permissions using Kubernetes RBAC. Grant the `create` verb on `namespaces` only to the users and service accounts that require it, and audit namespace creation events.
