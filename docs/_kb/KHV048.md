## Issue description

A pod with a writable hostPath mount to /var/log can create symlinks in the host's /var/log directory. An attacker can then run commands on such a pod through the kubelet and traverse-read arbitrary files on the host filesystem.

## Remediation

Avoid granting pods hostPath mounts to /var/log or other sensitive host directories. Enforce Pod Security Standards (or PodSecurityPolicies) that restrict hostPath volumes.
