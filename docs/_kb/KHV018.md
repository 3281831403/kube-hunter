# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could patch an existing pod. Patching a pod allows an attacker to compromise and control it, for example by injecting a sidecar container running attacker-controlled code.

## Remediation

Restrict pod modification permissions using Kubernetes RBAC. Grant the `patch` and `update` verbs on `pods` only to the users and service accounts that require it, and audit pod modification events.
