# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could create a PRIVILEGED pod in the cluster. A privileged pod has full access to the host, so creating one would gain an attacker FULL CONTROL over the cluster.

## Remediation

Restrict pod creation permissions using Kubernetes RBAC, and enforce Pod Security Standards (or PodSecurityPolicies) that forbid privileged containers across the cluster.
