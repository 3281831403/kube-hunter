# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could patch an existing cluster role. Patching a cluster role might give an attacker the option to grant new permissions (such as creating pods with custom roles) within the whole cluster scope.

## Remediation

Restrict cluster role modification permissions using Kubernetes RBAC. Grant the `patch` and `update` verbs on `clusterroles` only to the users and service accounts that require it, and audit cluster role modification events.
