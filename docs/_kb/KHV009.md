# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could delete a namespace in the cluster. Deleting a namespace removes all of the workloads and resources it contains, allowing an attacker to disrupt applications and destroy data.

## Remediation

Restrict namespace deletion permissions using Kubernetes RBAC. Grant the `delete` verb on `namespaces` only to the users and service accounts that require it, and audit namespace deletion events.
