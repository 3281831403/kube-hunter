# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could delete a role in the cluster. Deleting a role might allow an attacker to affect access to resources in the namespace, disrupting the normal behavior of applications that rely on it.

## Remediation

Restrict role deletion permissions using Kubernetes RBAC. Grant the `delete` verb on `roles` only to the users and service accounts that require it, and audit role deletion events.
