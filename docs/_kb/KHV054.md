# {{ page.vid }} - {{ page.title }}

## Issue description

CAP_NET_RAW is enabled by default for pods. If an attacker manages to compromise a pod, they could potentially take advantage of this capability to perform network attacks (such as ARP poisoning) on other pods running on the same node.

## Remediation

Drop the NET_RAW capability from your workloads by setting `securityContext.capabilities.drop: ["NET_RAW"]` (or `drop: ["ALL"]`) on your pods or containers, and enforce it with Pod Security Standards.
