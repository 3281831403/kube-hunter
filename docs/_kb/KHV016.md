# {{ page.vid }} - {{ page.title }}

## Issue description

An attacker with access to the Kubernetes API could create a pod in the cluster. Creating a new pod allows an attacker to run custom code inside the cluster.

## Remediation

Restrict pod creation permissions using Kubernetes RBAC. Grant the `create` verb on `pods` only to the users and service accounts that require it, and use admission controllers to limit which images and configurations can be deployed.
